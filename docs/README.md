# JX3BOX Facedat 文档

本目录只记录 `@jx3box/jx3box-facedat` 组件包本身的架构、约束和改造规则。项目同时承担两种职责：

- 对外提供捏脸、体型数据的解析与展示组件；
- 通过 `src/App.vue` 提供本地开发演示页。

## 阅读顺序

1. [项目架构与业务边界](./architecture.md)：先理解入口、数据流、公共 API 和不可破坏的协议。
2. [国际化规范](./common/i18n-development-guide.md)：语言状态、词条结构和数据翻译边界。
3. [主题与样式规范](./design/style-guide.md)：CSS 变量、Element Plus 联动和样式作用域。
4. [响应式与移动端规范](./design/responsive-adaptation-guide.md)：组件级断点、布局降级和验收矩阵。

## 文档维护原则

- “当前状态”必须与仓库代码一致，尚未落地的能力统一写为“目标方案”。
- 本项目没有路由、SEO、小程序专用页面或全站页面壳，文档不得引用其他项目的对应结构。
- 改造涉及新的业务约束时，同步更新本文档；具体实现细节优先靠代码和测试表达。
- `raw/`、`assets/data/` 和 `tools/` 中的数据生成规则属于业务协议，不能按普通 UI 文案或样式文件处理。
